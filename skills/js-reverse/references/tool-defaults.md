# Tool Defaults

- `js-reverse_list_network_requests`: First check the default results on the first page; paginate only if insufficient
- `js-reverse_search_in_sources`: Defaults to `excludeMinified=true`
- `js-reverse_get_script_source`: Read only small snippets; for the full source, prefer `js-reverse_save_script_source`
- `js-reverse_break_on_xhr`: Only fill in URL substrings that reliably match
- `js-reverse_get_paused_info`: Defaults to checking `frameIndex=0` first
